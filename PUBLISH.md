# Publishing `dsh-inline-quote`

Status: pre-release checklist. The package lives in this directory; the `desktop` profile links to it.

## Decisions

- **npm name:** `dsh-inline-quote` — free on the npm registry as of 2026-10-26. `dsh-selection-quote` is a different plugin (richer comment UI); this one is the minimal native-chip implementation.
- **License:** MIT.
- **Distribution:** GitHub repository + npm package with the `dsh-plugin` keyword. dshmp.com indexes npm automatically (daily sync); there is no submission form and no human approval.
- **Maintenance:** as-is, best effort, no SLA. If DSH ships native quote support, deprecate the package (see `## Retirement`) and the market listing is marked archived automatically.

## What the release package must contain

The npm `files` list already ships only the runtime files: `index.js`, `client.js`, `cordis.patch.yml`, `locale/*.json`, `icon.svg`. `package.json` must additionally declare:

- `"name": "dsh-inline-quote"`, no `"private": true`
- `"repository"`, `"homepage"`, `"bugs"`
- `"keywords"` including `dsh-plugin`
- `"license": "MIT"`
- `"engines": { "node": ">=18" }`
- an `"author"` line with the desired public name

## One-time steps

1. **Create the GitHub repository.** Empty, named `dsh-inline-quote`, no README/license generated by GitHub.
2. **Create the npm account** (if needed). npm requires email verification; 2FA is recommended.
3. **Push the repository** from this directory:

   ```powershell
   git init -b main
   git add .
   git commit -m "feat: inline quote reference chips for DSH"
   git remote add origin https://github.com/anqifox/dsh-inline-quote.git
   git push -u origin main
   ```

4. **Publish to npm:**

   ```powershell
   npm login
   npm publish --access public
   ```

5. **Verify the market listing:** paste `dsh-inline-quote` into https://dshmp.com/en/check or wait for the daily sync. The listing appears within a day.

6. Optional: add the recipe to the curated list by opening a PR in `awesome-dsh-plugin/awesome-dsh-plugin` under `categories/ui-enhancements.md`.

## Retirement

When DSH ships native quote support, do not delete anything:

```powershell
npm deprecate dsh-inline-quote "Superseded by native DSH quote support; kept for reference only"
```

The market reads npm deprecation, marks the listing archived, and keeps its permalink. The GitHub repository can stay public or be archived with a final README note.
